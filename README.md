# FocusFlow

Minimalist productivity and flow hub featuring schedule calendar, active task management, sticky note fragments, procedural ambient soundscapes, and interactive flow timers.

**Ideas Deployed By : Md Istiak Islam**

## Features
- **Glassmorphic UI / UX**: Crystal-clear frosted glass styling with dual specular rims and smooth responsive layouts.
- **Dark & Light Mode**: Fluid instant toggle with theme persistence in local storage and adaptive particle canvas.
- **Custom Focus & Sprint Engine**: 25m focus, 50m sprint, short/long breaks, and customizable duration with visual SVG progress ring.
- **Web Audio Soundscapes**: Procedural Alpha Waves (10Hz focus beat), Soft Rain, Cosmic Noise, and Forest Breeze.
- **Interactive Daily Schedule & Calendar**: Month calendar navigator with day schedule time-blocking.
- **Daily Habit Streaks**: Interactive hydration, deep work, reading, and mindful walking habit tracking with streak counters.
- **Glass Fragments Scratchpad**: Auto-saving color-coded thoughts and notes with instant copy and search filtering.
- **Multi-Format Export Suite**: Plain Text (.TXT), Printable Report (.PDF), and High-Definition Snapshot (.JPG).
